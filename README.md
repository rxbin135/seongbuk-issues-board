# 성북구 지역문제 탐구 보드

초등학교 4학년 사회 「지역문제와 해결」 수업용 웹보드입니다. 서울 성북구에서 실제로 확인된 지역문제 32가지를 학생들이 태블릿으로 읽고, 상황·원인·해결방법을 스스로 정리해 캔바(Canva)에 옮겨 적는 데 씁니다.

## 쓰는 법

1. 카드를 누르면 글이 열립니다.
2. `📍 어디서` · `📰 지금 상황` · `🔎 왜` 를 읽고, 맨 아래 `💡 생각해 볼 점` 질문에 답합니다.
3. 답을 캔바에 정리합니다. 정답은 넣지 않았습니다.

닫기: 오른쪽 위 ✕, 바깥 배경 누르기, ESC 키. 카드 이동: 아래 `← 이전 문제` / `다음 문제 →` 버튼, 키보드 ←/→, 태블릿에서 좌우로 밀기.
