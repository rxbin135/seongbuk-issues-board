# 성북구 지역문제 탐구 보드

초등학교 4학년 사회 「지역문제와 해결」 수업용 웹보드입니다. 서울 성북구에서 실제로 확인된 지역문제 32가지를 학생들이 태블릿으로 읽고, 상황·원인·해결방법을 스스로 정리해 캔바(Canva)에 옮겨 적는 데 씁니다.

## 쓰는 법

1. 맨 위 `📌 캔바 정리 예시 보기` 를 눌러, 어떤 칸으로 나누어 정리하면 되는지 먼저 봅니다.
2. 카드를 누르면 글이 열립니다.
3. `📍 어디서` · `📰 지금 상황` · `🔎 왜` 를 읽고, 맨 아래 `💡 생각해 볼 점` 질문에 답합니다.
4. 답을 캔바에 정리합니다. 정답은 넣지 않았습니다.

예시 이미지는 모달로 크게 열리고, `원본 크기로 새 창에서 보기` 로 원본(1536×1024)을 띄울 수 있습니다.

닫기: 오른쪽 위 ✕, 바깥 배경 누르기, ESC 키. 카드 이동: 아래 `← 이전 문제` / `다음 문제 →` 버튼, 키보드 ←/→, 태블릿에서 좌우로 밀기.

## 파일

- `index.html` — 단일 파일. 외부 JS·CSS·폰트에 기대지 않습니다.
- `canva-example.jpg` — 맨 위 `📌 캔바 정리 예시 보기` 에 쓰는 캔바 예시 포스터(1536×1024, 538KB). `index.html` 이 `./canva-example.jpg` 상대 경로로 부릅니다. 두 파일을 같은 폴더에 두면 인터넷이 없어도 열립니다.
